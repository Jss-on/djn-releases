Installers for Kanku, a counter and stock program for shops. The program's Update button reads the newest release here. Source code is private.

![Kanku](brand/kanku-share.png)

Download the newest `kanku-setup-<version>.exe` and its `.sha256` from [Releases](https://github.com/Jss-on/djn-releases/releases/latest). Check the file against the hash before running it.
